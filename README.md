# 🕸️ Spokiee-Web

A dark, interactive web experience featuring glitch effects, animated UI, and a terminal-inspired interface. This project focuses on immersive storytelling through creative front-end interactions combined with a lightweight backend.

---

## 🚀 Features

- ⚡ Terminal-style interactive UI
- 🎭 Glitch effects and dynamic animations
- 🧠 Event-driven JavaScript interactions
- 🌐 Lightweight backend server (Node.js)
- 📦 Modular architecture (handlers, events, data)
- 🎨 Focus on user experience and visual storytelling

---

## 🛠️ Tech Stack

- JavaScript (Frontend + Backend)
- HTML / CSS
- Node.js
- Custom server (no heavy frameworks)

---

## 📂 Project Structure

/data → stores application data
/events → event-based logic
/handlers → request handlers
/public → frontend assets
server.js → main server entry point

---

## 🧠 What I Learned

- Building interactive UIs using JavaScript and DOM manipulation  
- Structuring a project with modular architecture  
- Handling events and separating concerns (handlers/events)  
- Creating a lightweight backend without heavy frameworks  
- Debugging complex UI behavior and animations  

---

## 🎯 Purpose

This project was created to explore creative front-end development while also integrating backend logic to simulate a complete web application experience.
